ORIGINAL 3D BROWSER SKIRMISH  •  VANGUARD vs CRIMSON SWARM

Mission: destroy the enemy Command Core in the north-east. Lose your own Core and the skirmish is over. Harvest Flux (blue crystals) and Alloy (orange veins), raise Relay Pylons for supply, raise a War Foundry, and march Lancers and Bulwarks on the Swarm.

🖱️ Select: left-drag box, double-click = same type, Ctrl-click = same type
🖱️ Order: right-click = move / attack / harvest
⌨️ A attack-move, S stop, H hold, B build menu
⌨️ 1–3 groups (Ctrl+1 set), Space jump to alert
📷 Camera: arrow keys, edge pan, wheel zoom, middle-drag, minimap click
👷 Workers auto-return cargo; idle-worker button (💤) top bar
