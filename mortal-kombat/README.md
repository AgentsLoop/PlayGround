# MORTAL COMBAT — original browser arcade fighter

Zero-dependency HTML5 Canvas game. Open `index.html` in any modern browser
(or serve the folder: `python3 -m http.server`).

- 1P vs CPU + 2P local · 4 distinct fighters · best-of-3 · 60s timer
- Punch / smash / spirit bolt / block · FINISH HIM finisher window
- Synthesized WebAudio (no files) · touch buttons · ARIA live · reduced-motion
- References (inspect-only, original in-game assets): see `references/*.json` + `../PROGRESS.md`
