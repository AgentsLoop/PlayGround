  • node --check game.js: SYNTAX_OK
  • Console/page errors during full run: 0
  • 9/9 scripted browser steps pass: title → select → countdown → keyboard drive + MG fire (foe 170→152 HP, score +6 via real input) → AI moves/fires on its own → pause/resume → 3-arena run to victory (hi-score 229836 persisted) → lives 3→2→1→0 to game over → retry restarts arena with lives refilled
  • Bugs found by the loop and fixed: keyboard fire keys never registered (keys.J vs keys.KeyJ), AI tick called nonexistent updateAI, death/clear timers desynced by pause (converted to in-update timers)
  • 60 fps in headless software rendering during combat

Decisions

  • Top-down follow camera instead of behind-car 3D: keeps combat readable + scope shippable; lookahead + shake preserve chase feel.
  • Free-for-all AI (everyone hunts nearest) mirrors TM deathmatch; AI uses same weapons/specials as player.
  • Parody roster (Sweet Fang / Warhog / Road Rat) keeps Sweet-Tooth archetype without copying assets.
  • All art + audio procedural (canvas/WebAudio): zero external runtime deps.

Known gaps / next

  • Split-screen/co-op explicitly out of scope (single-player vs AI).
  • Mobile/touch controls out of scope (desktop web target).
