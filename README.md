# PlayGround
Playground for browser game experiments

## Neon Courier: Signal Sprint
Pilot a neon courier drone through a compact city grid, collect all 8
signal orbs before the 60-second timer runs out, and dodge the patrolling
blockers (3 hull hits).

No build step, no dependencies — open `index.html` in any browser, or serve
the folder (e.g. `python3 -m http.server`) and visit the local URL.

- Move: `WASD` / arrow keys (touch D-pad on mobile)
- Pause: `P` / `Esc` · Restart: `↻ RESTART` button or `R` / `Space`
