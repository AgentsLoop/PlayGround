# PlayGround

Playground for browser game experiments.

## IRON MAYHEM — 3D vehicular arena combat (original, Twisted-Metal-inspired)

Playable game: [`twisted-arena/index.html`](twisted-arena/index.html) — serve over HTTP first:

```sh
python3 -m http.server 8765
# open http://localhost:8765/twisted-arena/
```

- Drive (WASD/arrows), aim turret (mouse), MG (click/Space), missiles (E/right-click), boost (Shift), pause (P), restart (R), unstuck (T), mute (M).
- 1v3 arena combat vs AI rivals, pickups, damage, win/lose, restart.
- Docs: [`twisted-arena/PROGRESS.md`](twisted-arena/PROGRESS.md) (canonical progress page + evidence), [`reference-assets/PROVENANCE.md`](reference-assets/PROVENANCE.md) (reference provenance).
