# PlayGround
Playground for browser game experiments.

## Playground Ops (Call of Duty–inspired arena shooter)
Open `index.html` in a browser (no build step, no external assets).

WASD move · mouse aim · click/Space fire · right-mouse ADS · R reload · Shift sprint · P pause.
Survive endless waves with CoD-style health regen, killfeed, tac-map, compass, and scavenger ammo economy.
