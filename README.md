# PlayGround
Playground for browser game experiments

## Neon Parcel Panic
Top-down neon courier game. Steer with WASD/arrows, pick up glowing parcels,
deliver to the matching-color drop zone, dodge patrol drones. 90s clock,
3 lives, +100 pts and +5s per delivery. Restart with R or the button.

- Play: open `project/index.html` (or root `index.html`) in a browser, or serve the repo and visit it.
- No build step, no assets — single self-contained Canvas 2D file.
